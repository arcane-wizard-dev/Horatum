# Horatum

[![GitHub Release](https://img.shields.io/github/v/release/arcane-wizard-dev/Horatum?color=blue&logo=github&cacheSeconds=600)](https://github.com/arcane-wizard-dev/Horatum/releases) [![GitHub Release Date](https://img.shields.io/github/release-date/arcane-wizard-dev/Horatum?color=blue&logo=github&cacheSeconds=600)](https://github.com/arcane-wizard-dev/Horatum/releases)

_Every second counts._

Horatum is a World of Warcraft addon that tracks the duration and results of supported boss encounters. A customizable timer shows the current fight’s duration, and the results are saved.

> ⚠️ **Important!** This addon requires **Arcane Wizard: Library**. See Installation & Quick Start for installation details.

## Key Features

**Combat Time Tracker** - Track the duration of the current encounter with a customizable display that fits into your interface.

**Combat Overview** (Planned) - A central overview of recorded encounter data is planned, making it easier to review results in one place.

## Features

Individual features and display options can be configured in the addon settings. Horatum supports an account profile and character profiles.

### Combat Tracking

* Automatically starts the timer for supported boss encounters and stops it when the game reports a victory or wipe.
* Features a clean, semi-transparent frame that displays the ongoing combat time.
* Saves victories and wipes and can post them to chat after combat.

### Display Customization

* The Combat Time Tracker can be moved anywhere on the screen.
* The size of the Combat Time Tracker can be easily adjusted to fit the user interface.

## Supported Languages & Flavors

* Languages: English, German, Russian
* Flavors: Forever, Retail

## Installation & Quick Start

> **Required Dependency:** This addon requires **Arcane Wizard: Library**. If you install Horatum via the CurseForge client, the library will be downloaded automatically. If you install the addon manually, via Wago, or through another third-party updater that does not resolve dependencies, you must download and enable the library separately.

To manage the addon, type the following commands in chat and press Enter:

* Type `/hrt` or `/horatum` to access the addon options menu.
* Type `/hrt changelog` or `/horatum changelog` to open the changelog.
* Type `/hrt tracker` or `/horatum tracker` to manually display the Combat Time Tracker.
